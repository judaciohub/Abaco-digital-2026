## 🌐 Passo a Passo - Upload Manual

### 1️⃣ Acesse seu repositório no GitHub
   - Vá para: https://github.com/[seu-usuario]/[seu-repositorio]

### 2️⃣ Clique em "Add file" → "Upload files"
   - Ou arraste os arquivos diretamente para a página

### 3️⃣ Selecione os arquivos
   Arraste estes arquivos da pasta:
   ```
   C:\Users\SUPORTE TI\Documents\Aplicativos\abaco 2026
   ```
   
   - ✅ index.html
   - ✅ server.py
   - ✅ README.md
   - ✅ CHANGELOG.md
   - ✅ .gitignore

### 4️⃣ Escreva a mensagem de commit
   ```
   Atualização v28/04/2026
   
   - Renomeado CABEÇA VIVA para LOTE
   - Adicionado campo para número/nome do lote
   - Invertida ordem de PALETA e BARRIGA
   - Adicionada documentação (README e CHANGELOG)
   ```

### 5️⃣ Escolha a branch
   - Se for atualização: selecione "Commit directly to the main branch"
   - Se quiser revisar: selecione "Create a new branch"

### 6️⃣ Clique em "Commit changes"
